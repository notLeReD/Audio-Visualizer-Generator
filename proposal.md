# Audio-Visualizer Generator

## Repository
https://github.com/notLeReD/Audio-Visualizer-Generator

## Description
This project will generate a visualizer for any audio (mainly music) given as input. This is relevant to media/digital arts because audio visualizers are
commonly used in music experiences such as music videos, concerts, and visualizers.

## Features
- A way to cut the audio into smaller sections
	- Mainly for the music video aspect, there needs to be a way to select what section of the audio should be visualized
- Different Visualizers
	- Different options can be given for the visualizer (bars, circle, waveform, etc).
- A way to export the visualizer
	- The visualizer can be exported an external file, such as an MP4 for other purposes.

## Challenges
- How to import/work with audio in Python?
- How to export graphics/visuals as a MP4 in Python?
    - Stretch: can you export it as template files for motion graphic applications (AE/DaVinci Resolve, etc.)
- Different types of audio-visualizers to use as the visualizer options?
- How to implement these visualizers in Python?

## Outcomes
Ideal Outcome:
- An application that allows you to export visualizers of your imported audio.

Minimal Viable Outcome:
